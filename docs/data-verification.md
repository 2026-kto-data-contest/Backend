## 3. 테스트 픽스처 사용

골든 3파일은 테스트 클래스패스 리소스로 로드한다:

```
getClass().getResource("/golden/20260728_manifest.json")
getClass().getResource("/golden/20260728_brewery_raw.json")
getClass().getResource("/golden/20260728_product_raw.json")
```

파이프라인 검증 단계(`pipeline/verify`)가 manifest의 sha256과 행수를 대조해 수집·정규화 결과의 재현성을 보증한다.
